# NOVA OS — Тестирование и верификация (TESTING.md)

## Стратегия тестирования

NOVA OS включает автоматизированные и модульные тесты для подсистем ядра рабочей среды:
1. **NOVA Setup & Desktop**: Проверка валидации пользователей, локализации i18n, поиска приложений, виртуальных рабочих столов и управления файлами.
2. **NOVA Shield**: Комплексное тестирование всех 5 уровней анализа (сигнатурный, статический, песочница, репутация, эвристика) и карантинного хранилища.
3. **NOVA Thermal Guard**: Тестирование датчиков, температурных порогов, голосовых оповещений ИИ и безопасного отключения с помощью виртуальных данных.
4. **NOVA AI**: Проверка обработки команд, анализа логов, безопасного предпросмотра редактирования файлов и отмены изменений.
5. **Профили системы**: Проверка переключения между NOVA Lite, Gaming, Dev и Home.

## Запуск всех автотестов

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Тестовые примеры для безопасности (NOVA Shield)

Для проверки предупреждающих диалогов и блокировки подсистемой NOVA Shield предусмотрены тестовые файлы:

  ```bash
  echo 'X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*' > test_eicar.com
  ```
