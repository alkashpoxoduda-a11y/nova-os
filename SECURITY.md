# NOVA OS — Политика безопасности (SECURITY.md)

## Архитектура защиты NOVA OS

NOVA OS реализует многоуровневую модель защиты:

### 1. NOVA Shield (5 уровней анализа)
- **Signature Scan**: Проверка сигнатур известных угроз через ClamAV / локальную БД.
- **Static Analysis**: Анализ структуры бинарных файлов и скриптов без выполнения.
- **Behavior Analysis**: Запуск в изолированной песочнице (`bubblewrap` / `firejail`). Если песочница недоступна, файл не выполняется на основной системе.
- **Reputation Check**: Проверка цифровых подписей, издателя и SHA256 хешей.
- **Heuristic Analysis**: Поиск подозрительных сочетаний команд, обфускации и автозапуска.

### 2. Безопасность ИИ (NOVA AI)
- Микрофон не записывает аудио без явного согласия пользователя.
- Пользовательские файлы не отправляются на сторонние серверы без подтверждения.
- Команды с правами суперпользователя и изменения файлов требуют явного подтверждения (с предпросмотром изменений и возможностью отмены).

### 3. Защита оборудования (NOVA Thermal Guard)
- Отслеживание физических датчиков температуры CPU/GPU.
- Пошаговые предупреждения и защита от перегрева с безопасным сохранением логов и остановкой служб.

## Сообщение об уязвимостях

Если вы обнаружили уязвимость в NOVA OS, пожалуйста, отправьте отчет по адресу security@nova-os.org.
