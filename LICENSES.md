# Лицензии и сторонние компоненты NOVA OS

NOVA OS распространяется под свободной лицензией и включает следующие проверенные сторонние компоненты:

1. **Debian GNU/Linux** (GPL / DFSG) — базовая операционная система и пакетная база.
2. **KDE Plasma & Qt Framework** (LGPL v3 / GPL v2) — графическое окружение и визуальные библиотеки.
3. **Linux Kernel** (GPL v2) — операционное ядро системы.
4. **ClamAV Engine** (GPL v2) — подсистема сигнатурного анализа вредоносного ПО.
5. **Bubblewrap / Firejail** (LGPL v2.1 / GPL v2) — песочница для безопасного изоляционного запуска процессов.
6. **Steam & Proton** (Valve Corporation / Wine dual license) — подсистема совместимости и запуска игр.
7. **Python / PySide6 / Qt** (PSFL / LGPL v3) — системный инструментарий оболочки NOVA OS.

Все компоненты соответствуют их исходным лицензиям и открыты для распространения.
